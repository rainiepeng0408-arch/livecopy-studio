# LiveCopy · 直播文案工作室

> 一句英文直播意图，五个市场的直播文案同时就绪——附像素级 QA 校验与文化适配提示。

**在线访问**：本仓库开启 GitHub Pages 后自动生成（`你的用户名.github.io/livecopy-studio`）

## 这是什么

面向直播电商出海场景的跨市场文案工具：输入一句英文直播意图（如促销、进房、送礼、涨粉），自动生成**英 / 中 / 日 / 韩 / 西**五个市场的直播字幕与按钮文案，并用**真实像素测量**校验按钮会不会溢出、字幕会不会挡住商品卡，同时给出每个市场的文化适配提示。

核心判断：

- **重新写，而不是翻译**——按「意图 + 语气」在每个市场重新生成，而不是逐词机翻；
- **校验真实像素，而不是字符数**——离屏 DOM 实测宽度与行数，和线上同一套渲染规则；
- **把文化经验显性化**——资深运营才知道的「这个市场不能这么说话」，写进界面。

## 技术要点

- 纯 HTML / CSS / JS，无框架、无构建，`file://` 直接可跑
- 意图分类：多语言正则识别促销 / 进房 / 送礼 / 关注四类意图
- 文案数据：75 组文案包（5 语言 × 3 语气 × 5 意图）
- 像素测量：离屏 DOM `estimateLines()` / `ctaOverflows()` 实测按钮宽度与字幕行数
- 响应式 980 / 720 双断点；`aria-label`、`focus-visible`、`prefers-reduced-motion` 可访问性支持
- 本地规则引擎接口化设计，未来可无缝替换为 LLM 生成
